KA Refresh Setup

Two steps. Takes about 2 minutes. You only do this once.

1 Install Tampermonkey

Tampermonkey lets you add small helper scripts to Chrome. It's free, safe, and widely used.

Click the button below. On the Chrome Web Store page, click Add to Chrome, then Add extension.

Install Tampermonkey →
Already have Tampermonkey? Skip to Step 2.
2 Install the KA Refresh script

Click the button below. Tampermonkey will open and ask if you want to install the script. Click Install.

Install KA Refresh script →
The script only runs on Salesforce pages. It cannot read any other websites.
That's it. Open any KA in Salesforce and you'll see a "↑ Sync to Drive" button in the top-right corner. The first time you click it, it will ask for your first name — type it once and it remembers.
